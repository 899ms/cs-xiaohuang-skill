# 网红知识课风格索引

这六套是为“知识内容被看完、被收藏、被转发”设计的视觉系统。它们不是把网红元素贴在封面上：每套都要覆盖封面、章节、概念、案例、步骤、对比、练习和结尾。

## 默认预览

知识课程默认制作三个真实首屏，使用用户自己的课程标题、案例或 logo：

1. [笔记手帐](styles/notes-collage.md)：最亲切、最适合首次学习与中文知识内容。
2. [杂志静奢](styles/quiet-editorial.md)：最可信、最适合观点与案例型课程。
3. [果冻多巴胺](styles/tactile-pop.md)：最有记忆点、最适合效率与成长主题。

只在主题匹配时，用其余三个替换其中一个方向：粗粝手作用于个人经验与社群；像素未来用于 AI/工具；液态玻璃用于产品与商业系统。

## 六种网红风格

| 风格 | 核心气质 | 最适合的课程 | 不适合 |
| --- | --- | --- | --- |
| [笔记手帐](styles/notes-collage.md) | 真实、亲近、可收藏 | 入门课、成长、职场方法、生活方式 | 财务、法律、严肃汇报 |
| [粗粝手作](styles/marker-zine.md) | 活人感、表达欲、观察 | 个人经验、创作者、复盘、社群课 | 高端企业培训、密集数据 |
| [果冻多巴胺](styles/tactile-pop.md) | 轻快、明亮、奖励感 | 效率、习惯、学习法、年轻团队 | 长篇严肃理论、风险决策 |
| [杂志静奢](styles/quiet-editorial.md) | 克制、观点、可信 | 商业认知、品牌、案例、创始人课 | 游戏化互动、复杂流程 |
| [像素未来](styles/retro-pixel.md) | 新锐、实验、科技感 | AI 工具、自动化、开发者、趋势课 | 医疗、法律、传统企业课堂 |
| [液态玻璃](styles/liquid-glass.md) | 高级、空间感、产品感 | 产品方法、商业模型、系统思维 | 长段中文、低端设备场景 |

## 选择规则

- **想提升收藏感和亲近度**：笔记手帐。用圈画、贴纸、纸张层级服务于讲解，不做碎片拼贴。
- **想让课程更像本人而不是 AI**：粗粝手作。手写、涂改、实拍细节和不规则边缘必须来自真实内容。
- **想提高记忆点和课堂活力**：果冻多巴胺。用一个奖励色、一种软材质和清晰的步骤反馈。
- **想建立专业信任**：杂志静奢。用强标题、真实证据、编辑式留白和精确的叙事节奏。
- **想为 AI/工具主题做传播开场**：像素未来。点阵与终端元素只能承载标签、状态与短标题。
- **想让产品/模型显得现代**：液态玻璃。玻璃层只用于导航、状态和重点，正文回到不透明阅读面。

## 不可省略的质量门槛

- 一套 deck 只能有一个主风格。混搭只允许借一个辅助元素，必须明确主从关系。
- 任何风格都要以固定 1920×1080 舞台的可读性优先；文字过多先拆页，不缩小。
- 不固化第三方 logo、远程视频、素材链接或参考品牌。没有资产时，用 CSS 纹理、线条、形状和授权素材替代。
- 高能动效只用于封面、章节与关系揭示；所有正文必须在减少动态效果模式下立即可读。
