# 杂志静奢 / Quiet Editorial

## 设计意图

像一篇精编的杂志长文：有判断、有证据、有停顿。它适合让课程显得成熟可信，而不是冷漠昂贵。

## 视觉系统

- 背景：骨白、炭黑或雾灰，一套只选择一个主背景。
- 强调：暗红、苔绿或灰银，只用于关键字与引文。
- 字体：标题采用高对比 serif 或 italic serif；正文保持干净无衬线。
- 图形：真实照片裁切、大留白、细分割线、页边注、引语和大数字。

## 课程页面语法

| 页面 | 构图 |
| --- | --- |
| 封面 | 一句观点占据画面，辅以少量课程信息。 |
| 章节 | 一个问题、一张真实图片或一处大留白。 |
| 概念 | 左侧结论，右侧给出两条展开。 |
| 案例 | 一张证据图、一个数据或一段短引文。 |
| 步骤 | 编辑式纵向注释，不做复杂流程图。 |
| 对比 | 用两句不同判断和一条证据完成转折。 |
| 练习 | 一道值得停下来思考的问题。 |
| 结尾 | 回到封面观点，但给出升级后的答案。 |

## 动效与限制

使用慢淡入、照片轻裁切和文字遮罩。正文避免大面积黑底小灰字；不使用闪烁、霓虹和繁杂玻璃层。
