# Editorial Noir

## 设计意图

像一篇精心编辑的长文：克制、留白、可信，适合把课程组织成观点、证据、转折与结论。

## 视觉系统

- 背景：墨黑、骨白或深灰，整套只选择一种主背景。
- 强调：灰银、暗红或低饱和酸性绿，仅作局部点题。
- 字体：正文为简洁 sans；标题用高对比 serif 或 italic serif，突出关键 2–4 个字。
- 图形：横向裁切的真实照片、细分割线、引语符号、页边注释和大号数字。

## 页面语法

| 页面 | 构图 |
| --- | --- |
| 封面 | 一句主张占满画面，辅以小型作者/课程信息。 |
| 章节 | 黑白摄影或纯色留白上放问题。 |
| 概念 | 左侧大结论，右侧是两三句展开。 |
| 证据 | 一张真实素材、一个数字或一段短引文。 |
| 转折 | 用前后两句对照，强调改变判断的证据。 |
| 步骤 | 竖向编辑标注而非正式流程图。 |
| 练习 | 写给学习者的一段提问，保留安静的答题空间。 |
| 结尾 | 重复但升级封面的主张。 |

## 动效与互动

- 采用淡入、轻微文字遮罩和照片裁切移动；节奏比其他风格更慢。
- hover 可以显示引文来源或照片说明，但不把正文做成交互杂志。
- 不使用霓虹、过度粒子或巨大圆角组件。

## 适用与避免

适用于创始人观点、品牌叙事、复盘、职业成长和需要引发反思的课程。避免密集流程、复杂仪表盘和大量并列概念。
