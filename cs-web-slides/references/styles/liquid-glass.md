# 液态玻璃 / Liquid Glass

## 设计意图

让课程具有现代产品感和空间层次。玻璃只负责聚焦与状态，真正的知识内容必须落在不透明、可阅读的层面。

## 视觉系统

- 背景：深海蓝、柔和天空、产品渐层或用户提供的实拍背景。
- 强调：冷白、冰蓝、极少量珊瑚色。
- 字体：中性无衬线；重要判断用较大字重，不用花体。
- 图形：半透明导航、模糊光晕、细边框、柔和高光和深度分层。

## 课程页面语法

| 页面 | 构图 |
| --- | --- |
| 封面 | 真实背景或抽象空间上放一块标题玻璃。 |
| 概念 | 主结论放在不透明阅读区，辅助定义放玻璃标签。 |
| 案例 | 产品截图或照片为底，局部用玻璃注释。 |
| 步骤 | 透明层沿一条路径逐层堆叠。 |
| 对比 | 两个清晰状态面板，玻璃仅作边缘与焦点。 |
| 练习 | 用一个聚焦容器给出任务和反馈。 |
| 结尾 | 一张轻盈的总结层和明确 CTA。 |

## 动效与限制

可使用模糊、折射感高光和 3–6px 的悬停抬升。不要把每段正文塞进半透明卡片；低端设备或文字密集页自动降级为纯色背景与实线边框。
