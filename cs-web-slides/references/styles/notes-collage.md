# 笔记手帐 / Notes Collage

## 设计意图

像一份被认真圈画过的高质量笔记：让人感觉课程作者真的理解学习者会卡在哪里。亲切来自讲解痕迹，不来自随机贴纸。

## 视觉系统

- 背景：暖白纸张、浅灰横线或低对比方格。
- 强调：仅选红、蓝、黄中的两种，分别表示重点与行动。
- 字体：清晰中文无衬线为正文；标题可加入少量圆润手写或 serif。
- 图形：下划线、荧光笔、圆圈、便利贴、撕纸边和一张真实小图。

## 课程页面语法

| 页面 | 构图 |
| --- | --- |
| 封面 | 主标题像笔记页题头，一处圈画提出课程承诺。 |
| 概念 | 定义在纸张主区，旁边以箭头标出“为什么重要”。 |
| 案例 | 一张真实截图或照片，配三处编号批注。 |
| 步骤 | 3–5 张不规则便签沿阅读轨迹排列。 |
| 对比 | 左右两页笔记状态，中间用改写符号连接。 |
| 练习 | 空出答题区，只给一个问题与一个提示。 |
| 结尾 | 用一张“带走这页”式总结卡收束。 |

## 动效与限制

圈画、下划线和便签按阅读顺序出现；hover 只用于批注展开。每页最多一种纸张纹理、两种强调色和一张贴图，避免变成素材堆。
