# Swiss Signal

## 设计意图

让课程像一个可复用的思考工具。信息有节制、对齐精确，学习者能快速扫描“结论、依据、步骤和例外”。

## 视觉系统

- 背景：冷白或浅灰；文字为近黑。
- 强调：纯红、国际蓝或橙红中选择一个；辅助灰只用于次级说明。
- 字体：标题使用粗体无衬线，正文使用同家族常规字重；中英文数字对齐稳定。
- 图形：严格网格、粗横线、编号、箭头、圆点和大比例数字；不使用柔和玻璃卡片。

## 页面语法

| 页面 | 构图 |
| --- | --- |
| 封面 | 巨型课程题眼 + 网格坐标/编号；留出品牌位。 |
| 章节 | 满页编号与一句章节任务。 |
| 概念 | 上方结论，底部两栏放定义和证据。 |
| 框架 | 2×2、三段式或坐标轴；颜色只标注当前重点。 |
| 步骤 | 强编号的横向时间线或纵向轨道。 |
| 对比 | 固定列宽的 before/after；优先删减而非缩小字。 |
| 练习 | 大问题 + 三项检查清单。 |
| 结尾 | 课程地图回顾，点亮已经掌握的模块。 |

## 动效与互动

- 进入动效应呈现阅读顺序：编号 → 标题 → 图形 → 注解。
- 可用 1px 线条绘制、遮罩揭示和数字递增；不要使用弹跳、旋转和漂浮。
- hover 只强调图表的一条系列、一个象限或一个术语。

## 适用与避免

适用于商业模型、策略、产品、案例拆解、运营流程和带数据的知识课程。避免把每页做成满表格；复杂表格拆成多页。
