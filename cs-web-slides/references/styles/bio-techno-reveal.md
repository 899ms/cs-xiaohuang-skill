# Bio-Techno Reveal

## 设计意图

用“探索未知”的感觉为科技课程开场。它应该像一个精密观察界面，而不是赛博朋克装饰堆叠。

## 视觉系统

- 背景：深黑、深酒红或暗蓝黑；内容区必须保留高对比的阅读面。
- 强调：信号红、冷白和少量电蓝。
- 字体：简洁 monospace 用于数据标签，清晰 sans 用于标题和正文。
- 图形：技术网格、同心弧、坐标刻度、局部光圈、放大的真实产品或用户资产。

## 页面语法

| 页面 | 构图 |
| --- | --- |
| 封面 | 全幅核心图片/抽象物 + 小标题块 + 一条观察刻度。 |
| 章节 | 暗场与一个发光问题，单一弧线引导焦点。 |
| 概念 | 左文右图；图中用一个探照圈揭示关键局部。 |
| 框架 | 同心圆、能力层级或信号轨道，不超过四层。 |
| 步骤 | 沿一条发光轨道推进，当前步骤清晰高亮。 |
| 对比 | 两个暗场状态，用扫描线或遮罩揭示差异。 |
| 练习 | 只保留一个观察任务，避免持续视觉噪声。 |
| 结尾 | 让初始图像全貌显现，回应封面问题。 |

## 动效与互动

- 封面可用一次性的慢速缩放、光标聚焦或遮罩揭示；进入正文后改为较轻的线条绘制。
- 不将每页都绑定鼠标探照；触摸设备必须有静态等价状态。
- 禁止高速闪烁、自动循环警报和影响阅读的扫描效果。

## 适用与避免

适用于 AI、硬件、未来工作、产品创新和技术趋势课程。没有高质量核心视觉时，选择 CSS 网格/弧线而不是伪造复杂人物或远程素材。
