# 粗粝手作 / Marker Zine

## 设计意图

把真实的观察、涂改和个人判断直接放进课堂。它追求“活人感”，但不是故意做丑；文字层级必须比手写装饰更稳定。

## 视觉系统

- 背景：奶油白、复印纸灰或低饱和色块。
- 强调：马克笔黑、番茄红、克莱因蓝或荧光黄。
- 字体：正文清晰无衬线；手写仅用于 2–6 字的情绪标记和箭头。
- 图形：不规则边框、粗线箭头、涂改、印章、实拍细节、剪报纹理。

## 课程页面语法

| 页面 | 构图 |
| --- | --- |
| 封面 | 大判断 + 一句像作者写下的旁注。 |
| 章节 | 用手写编号与粗横线切换话题。 |
| 概念 | 结论先行，旁边留下“常见误解”的叉号批注。 |
| 案例 | 原始材料的局部放大，圈出一个关键细节。 |
| 步骤 | 用粗箭头推进，每一步附一个真实提醒。 |
| 对比 | 错误版本被划掉，正确版本被重新写出。 |
| 练习 | 像工作纸一样留出填空与自检项。 |
| 结尾 | 一句个人化的行动宣言。 |

## 动效与限制

使用线条绘制、印章落下和短距离进入。手写字体不得承载整段内容；不使用伪造涂鸦、无关表情或过密彩色笔触。
