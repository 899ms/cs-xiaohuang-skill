# 像素未来 / Retro Pixel

## 设计意图

将“正在连接新工具、新系统”的兴奋感，转成可读的状态语言。像素是标签和节奏，不是把整堂课做成游戏界面。

## 视觉系统

- 背景：黑色、深灰或极深靛蓝。
- 强调：荧光绿、信号蓝、橙色任选一个。
- 字体：像素/点阵字体只用于标题、编号和状态；中文正文必须用普通无衬线。
- 图形：像素网格、状态条、命令符、图标和短标签。

## 课程页面语法

| 页面 | 构图 |
| --- | --- |
| 封面 | 两行短题眼 + 一枚系统状态标签。 |
| 概念 | 大术语与一个输入/输出关系。 |
| 案例 | 以仪表状态表示工具前后的差异。 |
| 步骤 | 像状态机一样逐格点亮。 |
| 对比 | 用亮/灭、在线/离线等状态表达变化。 |
| 练习 | 设计一个极小的输入到输出实验。 |
| 结尾 | 显示最终状态和下一步链接。 |

## 动效与限制

可用像素点亮、数字计数和状态切换；触摸设备必须直接显示最终状态。严禁点阵字体承载长段中文、扫描线覆盖全文或无意义故障闪烁。
