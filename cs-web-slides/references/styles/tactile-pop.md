# 果冻多巴胺 / Tactile Pop

## 设计意图

让学习过程具有“完成一个小任务就获得反馈”的轻快感。软材质和明亮色彩是奖励机制，不是儿童化包装。

## 视觉系统

- 背景：奶油白、浅天蓝、淡紫或低饱和渐层，每套最多两种底色。
- 强调：珊瑚橙、葡萄紫、酸橙绿中选择一个主奖励色。
- 字体：粗圆无衬线标题 + 高可读正文。
- 图形：软胶按钮、充气字、圆润进度条、黏土球、星形和大号数字。

## 课程页面语法

| 页面 | 构图 |
| --- | --- |
| 封面 | 大标题 + 一个 3D 软材质核心物件。 |
| 概念 | 用一张轻量“问题 → 解法”关系图。 |
| 案例 | 成果数字像奖励徽章一样被突出。 |
| 步骤 | 进度条或连续圆点标出当前关卡。 |
| 对比 | 两个柔软容器显示前后状态。 |
| 练习 | 用小挑战、计时或完成勾号组织任务。 |
| 结尾 | 以“现在就试一次”的明确 CTA 收束。 |

## 动效与限制

可使用轻微弹性、计数与按钮高光；所有弹性在 500ms 内完成。避免全屏漂浮球、五种以上高饱和色与阴影过重的卡片墙。
