# Liquid Metal Ops

## 设计意图

把“成熟的系统正在可靠运行”变成视觉感觉。高级感来自克制的材质与执行节奏，而不是玻璃拟态泛滥。

## 视觉系统

- 背景：纯黑到石墨黑；文字用冷白与中灰。
- 强调：雾银、冰蓝或极少量橙色。
- 字体：干净的中性 sans；课程结论中的少数字词可使用 italic serif。
- 图形：细边框、金属光泽按钮、低对比渐变、系统图标和明确的运行状态。

## 页面语法

| 页面 | 构图 |
| --- | --- |
| 封面 | 底部居中的课程承诺，背景仅保留轻微材质。 |
| 章节 | 编号、操作名和一条精致分割线。 |
| 概念 | 结论在上，下面分为原则与应用。 |
| 框架 | 模块关系用细线与状态点连接。 |
| 步骤 | 一条运营轨道，清晰标出输入、处理和结果。 |
| 对比 | 旧流程/新流程左右对照，状态而非装饰负责区分。 |
| 练习 | 管理者视角的决策题和检查点。 |
| 结尾 | 重申可执行的下一步，配一个简洁 CTA。 |

## 动效与互动

- 金属高光可仅在按钮、导航或重点线条 hover 时横向掠过一次。
- 页面进场使用淡入与 12–20px 位移，避免大范围毛玻璃模糊。
- 复杂图形按系统顺序出现，不能让特效遮住内容。

## 适用与避免

适用于企业 AI、运营、管理、组织流程和高层知识课。避免用于需要亲切感的入门培训；这种风格不能把所有内容都放进带边框的深色卡片。
