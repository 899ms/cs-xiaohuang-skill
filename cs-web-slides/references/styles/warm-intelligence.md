# Warm Intelligence

## 设计意图

把复杂知识讲得像一位耐心的人在桌边解释。它有温度，但不是儿童化；画面应帮助学习者降低进入门槛，而不是用装饰替代解释。

## 视觉系统

- 背景：暖白、浅米或极淡纸张纹理；主文字为炭黑。
- 强调：番茄红、深墨绿或湖蓝三选一；只用于关键结论、当前步骤和互动提示。
- 字体：中文正文使用稳定的无衬线；标题可配一款温和的 serif，但仅用于课程标题、章节句和总结。
- 图形：圆角不超过 12px；使用手绘箭头、纸张裁边、点阵、便签和简单线性物件来解释关系。

## 页面语法

| 页面 | 构图 |
| --- | --- |
| 封面 | 大标题 + 一个可见隐喻物件；不超过一行副标题。 |
| 章节 | 一个问题句，配短横线、页码与色块。 |
| 概念 | 左侧定义，右侧用人物/物件/箭头把关系画出来。 |
| 步骤 | 3–5 个连续节点，当前节点使用强调色。 |
| 对比 | 前后两个状态并置，中间展示发生的动作。 |
| 练习 | 给出一个小场景、一句提问和足够的思考留白。 |
| 结尾 | 一句可带走的判断 + 下一步行动。 |

## 动效与互动

- 元素以 80–160ms 的间隔从下方轻微出现；关系箭头在文字之后绘制。
- hover 只用于词汇卡、例子或可点击的练习入口，幅度不超过 4px。
- 光标效果保持柔和，不使用持续闪烁、扫描线或强粒子。

## 适用与避免

适用于零基础学习、中文课程、工作方法、沟通、效率与个人成长。避免堆满便利贴和插画；每页仍要有一条明确结论。
