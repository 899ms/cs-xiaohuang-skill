# Pixel Signal

## 设计意图

给技术知识一个新锐、实验性的发射感。像素元素是信号语言，不是怀旧游戏皮肤。

## 视觉系统

- 背景：纯黑或极深灰；内容文字为白色。
- 强调：一个明亮信号色，例如荧光绿、钴蓝或橙色。
- 字体：标题可以使用点阵/像素展示字体；正文必须回退为清晰无衬线。
- 图形：像素颗粒、低分辨率符号、数字标尺、胶囊导航和简洁的视频/照片容器。

## 页面语法

| 页面 | 构图 |
| --- | --- |
| 封面 | 两行像素题眼 + 信号色状态标签。 |
| 章节 | 单个像素符号和章节编号。 |
| 概念 | 大术语 + 右侧一个小型示意或代码式标签。 |
| 框架 | 模块化积木、四象限或栅格化能力图。 |
| 步骤 | 以进度条/状态机呈现，而不是普通箭头。 |
| 对比 | 用亮灭状态和数字差异表现前后变化。 |
| 练习 | 设计一个“输入 → 输出”小实验。 |
| 结尾 | 以最终状态和下一步链接收束。 |

## 动效与互动

- 使用像素逐步点亮、数字计数和状态切换；动画时长短且可预测。
- hover 适合显示术语定义或模块状态。
- 保持无动画的最终状态完整，不让点阵字体承担段落阅读。

## 适用与避免

适用于 AI 工具、开发者教育、自动化、创作技术与年轻创作者课程。避免用于正式董事会培训、法律合规或长篇中文正文。
