# 设计发现

## 需要确认的最小信息

若用户没有给足上下文，一次性确认这些影响结构的项：

1. 演示用途与受众：路演、发布、课堂、内部同步、异步阅读或作品展示。
2. 内容来源与想要的篇幅：现成材料、粗略笔记或只有主题。
3. 演讲密度：现场讲解（低密度）或阅读转发（高密度）。
4. 必须保留的 logo、截图、人物图、产品图与品牌色。
5. 审美线索：喜欢/不喜欢的参考、品牌、情绪或场景。

若用户只给了主题，先拿到上述信息再做预览。若提供内容、用途和品牌线索已足够，避免追加形式化问题，直接做大纲和 3 个预览。

## 三个预览的构成

预览应该让用户看见“如果整套 deck 用这个系统会是什么样子”，而不是展示色板。每个预览为完整 1920×1080 的真实封面页，使用：

- 演示真实标题与副标题；
- 拟定的字体配对；
- 完整色彩、背景与装饰语汇；
- 至少一个该 deck 会复用的构图组件；
- 克制但可感知的入场动效；
- 用户提供的 logo（如适合）。

以下三类形成一个默认的有效对比：

| 方向 | 目标 | 常用手法 |
| --- | --- | --- |
| 克制编辑感 | 可信、清楚、高级 | 网格、强留白、报刊式排版、低饱和点缀 |
| 强记忆点 | 让用户快速有偏好 | 深色舞台、巨型字体、鲜明一色强调、艺术化图形 |
| 内容定制 | 让设计与主题绑定 | 从行业、隐喻、产品形态或故事场景提炼独特视觉母题 |

避免三个只是换颜色的同一个排版。对于医疗、金融、政府或严肃内部决策，三者仍应专业，变化可以体现在排版、纹理、信息结构与克制程度，而非加入不合时宜的霓虹效果。

## 大纲与密度

低密度演讲 deck 的典型节奏：

1. 题眼或反直觉结论
2. 读者熟悉的问题
3. 证据、故事或转折
4. 方法/产品如何改变关系
5. 结果与下一步

高密度阅读 deck 允许比较、步骤和数据，但每页仍应该有一个清晰结论。遇到超过 6 个同级项目、较长表格或解释段落，优先拆为两页以上或改用逐层呈现。

## 视觉选择的判断

- 标题适合用有辨识度的展示字体，正文优先选择中英文都稳定的易读字体。
- 尽量选一个主色、一个强调色、一个中性色系统；颜色服务于层级与状态，不能平均撒满。
- 选定一个可重复的图形语汇，例如胶片裁边、瑞士网格、数据轨迹、蓝图细线或纸张拼贴；全套重复“语汇”，而不是重复一张版式。
- 动效表达因果、顺序、层级和焦点。没有意义的无限漂浮与大量同时弹跳会削弱阅读。
