# 质量检查清单

## 视觉与叙事

- 每页只有一个主要判断，标题能独立读懂。
- 首尾、章节和内容页具有节奏变化，但字体、色彩、装饰语汇与间距保持同一系统。
- 文字有足够对比度，边缘和投影不影响阅读；没有段落塞满卡片或小到难以在投影上阅读。
- 图片、图表、logo 与截图清晰、比例正确、未被裁掉关键信息。
- 设计没有“模板标签”、占位符、重复演示文案或无意义的 AI 装饰。

## 行为与适配

- 1280×720、1920×1080 与窄屏竖向视口下，始终只显示一个等比 16:9 舞台。
- body 与 viewport 没有滚动条；无文本溢出、面板遮挡或跳动布局。
- 首次加载、前进、后退、Home/End、空格、点击导航、触控滑动均正常。
- 每次进入 slide 时动效状态正确，`prefers-reduced-motion` 下内容立即可读。
- 编辑模式不会误触翻页；退出编辑模式后导航恢复。

## 交付

- 在本地通过 HTTP 静态服务器打开过一次，确认相对资源能加载。
- 交付目录只包含所需文件，不包含预览草稿、原始敏感材料或临时导出。
- 如用户需 PDF，说明 PDF 是静态快照，不包含网页交互和动画。
