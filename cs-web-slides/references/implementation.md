# 实现约定

从 `assets/web-slide-starter.html` 开始。它已经提供固定舞台、缩放、键盘/点击/触控导航、进度、入场动画、编辑模式和减少动态效果支持。生成时保留这些行为并替换示例内容。

## 文件结构

默认使用：

```text
my-web-deck/
├── index.html
└── assets/
    ├── logo.svg
    ├── product-shot-01.png
    └── source-photo.jpg
```

小型、无图片的 deck 可以只有一个 HTML。拥有大量图像、视频或从 PPTX 导出的品牌资源时，保持目录结构并使用相对路径，避免超大的 base64 单文件。

## 16:9 固定舞台

- 舞台内部尺寸必须始终为 1920×1080。
- JavaScript 使用 `min(window.innerWidth / 1920, window.innerHeight / 1080)` 计算缩放值。
- 只缩放整个舞台，不在媒体查询中重排 slide 内部的网格、字体或元素位置。
- 任何浏览器尺寸都不能产生页面滚动条。允许舞台四周出现信箱式空白。
- 以 `.slide.active` 显示当前页；切换前后应有 `opacity`、`visibility` 与 `pointer-events` 的一致控制。

## 导航与编辑

保留以下行为：

- ArrowLeft/ArrowRight、PageUp/PageDown、空格、Home、End；
- 点击舞台左/右四分之一前后翻页；点按控制按钮同样可用；
- 触控横向滑动；
- 当前页码、总页数与进度条；
- `E` 切换编辑模式；编辑时文本元素可改，Ctrl/Cmd+S 下载当前 DOM 的修改版本。

浏览器无法直接把修改写回本地 HTML 原文件，因此不要声称“已保存到源文件”；明确下载的是修改后的新版本。

## 动效

- 用 CSS animation 配合 `--delay` 让标题、正文和视觉按层级错开入场。
- 每次变页时重新触发新页入场动画；离开当前页后，动画元素不会保持遮挡状态。
- 转场时只保留一页可交互。
- hover、光标晕染或微型 3D 倾斜可以用于图片、链接和强调对象，不能干扰文本选择、按钮点击或触控导航。
- `prefers-reduced-motion: reduce` 下关闭自动播放和大幅位移动效，保留可读的静态最终状态。

## 内容和资源

- 将 CSS 变量放在 `:root`，至少包括背景、前景、主色、辅色、网格/阴影和速度。
- 所有 `img` 都应有准确 `alt`；装饰图可用空 alt。
- 图片使用 `object-fit`，不要拉伸人物、logo、截图或品牌物料。
- 外部字体可用标准 `<link>` 引入；重要交付场景需要离线时，改为打包已授权的本地字体或准备可读的字体回退。
- 不要把 API key、内部链接、用户隐私数据或原 PPTX 中不适合公开的备注直接带入网页。
