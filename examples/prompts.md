```text

正文图默认不使用页码或 PPT 标题；每张只表达一个关系，小黄必须执行关键动作；最后输出 contact sheet。

<粘贴文章>
```

## 3. 网页幻灯片 / 把 PPTX 网页化

```text
Use $cs-web-slides 把下面内容做成可在浏览器一页一页讲的网页幻灯片。
用于一场 12 页知识课 / 产品路演；先给我三个真实封面方向，确认后再完成整套 16:9 HTML 演示。
需要键盘、触控翻页和浏览器内改字；不要生成小黄 PNG 课件，也不要输出可编辑 PPTX。

<粘贴课程或演讲素材>
```

已有 PPTX 时：

```text
Use $cs-web-slides 把附件 PPTX 转换为网页演示。
保留原始图片、产品截图和品牌素材；先提取并确认逐页内容，再给我三个视觉方向。
```
