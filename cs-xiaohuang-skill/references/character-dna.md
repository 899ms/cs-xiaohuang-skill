# 小黄角色 DNA

每次生成、修改或验收都以 `../assets/reference-xiaohuang.png` 为唯一身份准则。本文件优先于风格、场景和媒介要求。

## 不变量

- **轮廓**：暖黄色、柔软而不规则的种子形身体，轻微倾斜；左下略鼓、右上略收。不是圆球、鸡蛋、水滴、梨子、水果或动物。
- **天线**：身体顶端伸出一根细长、略弯的线，末端为暖橙色**空心爱心轮廓**；不是实心红心、叶子、花、王冠、火焰或球形触角。
- **面部**：两只间距偏宽的黑色竖椭圆眼、极简小弧线嘴、淡橙腮红；不画鼻子、复杂眉眼、动漫大眼或写实五官。
- **四肢**：极细黑线，末端高度简化；不画鞋、手套或人类手掌。连接、陪伴、共创主题可让右手托起一个空心暖橙爱心。
- **配色**：主体 `#F6B72A`，高光 `#FFD86A`，阴影 `#E99A1B`，爱心 `#F59A23`，五官与四肢 `#151515`，背景 `#FFF9EF`。避免荧光黄、赛博蓝和彩虹扩色。

## 叙事职责

小黄代表连接、陪伴、点亮、降低距离，以及让知识真正被使用。它应在低科技工作台上完成一个能解释内容的动作：筛、捞、扛、拆、接、压、修、推、守、标记、拉线、扶梯、开闸或记录。
