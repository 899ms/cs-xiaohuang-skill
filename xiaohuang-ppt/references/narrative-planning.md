# 叙事规划

在设计页面前先选故事。每页一个主观点；把段落转成判断和关系，而不是把原文搬上去。

## Deck 类型

### 教学 / 课程

为什么重要 → 常见误解 → 核心概念 → 机制或结构 → 示例 → 常见坑 → 可执行方法 → 总结。

### 说服 / 方法论

真实痛点 → 旧做法为何失效 → 新判断 → 证据或例子 → 方法框架 → 实际改变 → 风险或异议 → 行动结论。

### 产品解释

用户卡点 → 产品主张 → 解决机制 → 关键工作流 → 差异点 → 使用场景 → 下一步。

### 复盘 / 项目报告

背景 → 目标 → 当前状态 → 关键发现 → 选择或计划 → 风险 → 下一步。

### 知识卡片

一个尖锐问题 → 核心解释 → 对比或机制 → 例子 → 一句带走的判断。

## Blueprint 字段

每页输出：页码、标题、主观点、archetype、内容块、小黄动作、主要物件、可见文字、图像 brief、来源支撑或假设。不得虚构事实性案例；需要示例但无来源时，标记为假设。
