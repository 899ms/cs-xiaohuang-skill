# 小黄 PPT 视觉 DNA

## 一句话定位

像一位创作者在暖白纸上画出的清晰产品草图：黑色轻手绘线条、充足留白、暖黄小黄承担关键动作；有一点怪，但一眼明白。

## 画布与母版

- 标准页面为 16:9 完整 raster 图；默认暖白 `#FFF9EF`，无纸纹、渐变、阴影、噪点、真实 UI 或整页边框。
- deck 多页先锁定母版：左上小页码（如 `03 / 10`）、顶部居中短标题、同一种细手绘下划线、稳定留白与线条粗细。文章正文配图默认不使用页码、顶部标题或课件下划线。
- 标题可作为 deck 导航，但不能做成海报式大字；非封面页即便标题较短，也保持与其他页光学等大。
- 中央动作 / 隐喻占画面约 40%–60%，至少留出三分之一安静空间。只让语义变化发生在中间区域，不能每页换母版。

## 线条、颜色与文字

- 黑色轻手绘线条需略有自然抖动；对象是纸箱、抽屉、筛网、漏斗、水管、闸门、梯子、邮筒、秤、怪表盘等低科技物件。
- 黄只给小黄；红橙仅标问题、警示或结果；蓝仅标反馈、状态或下一步。不要展开成彩色信息图。
- 可见中文：标题 5–12 字，2–5 个主标注，每张最多 6 个标注，每项 2–6 字。所有物件默认留白，除非其文字已在 `Required text only` 中。
- 小黄是主动作而非角落贴纸。需要多个步骤时也不要在每个节点重复角色；让同一只小黄贯穿一次连贯动作。

## 禁止外观

- 通用商业模板、课程课件卡片、正式架构图、数据仪表盘、完整 bullet list。
- 童趣卖萌、表情包、精致扁平矢量、3D 软胶（除非用户明确要求）、大面积色块、阴影和渐变。
- 深色 / 米黄背景、满屏箭头、密集标签、虚假英文、URL、水印、无意义小字。
