# 页面 Archetypes

按语义选页面，不按固定模板顺序排。每种结构都要让小黄执行关键动作，并保持轻手绘、留白和少文字。

| 内容语义 | 页面结构 | 小黄的典型动作 |
| --- | --- | --- |
| 开场主题 | 封面隐喻 | 点亮、递出或打开一个核心物件 |
| 一个概念 | 单概念解释 | 拆开、托起或标记概念 |
| 误解 vs 正解 | 左右对比 | 从左边拉线、搬到右边或剪断旧连接 |
| 前后变化 | 转化对比 | 修复、筛选、整理或推过一道门 |
| 步骤 / 管线 | 连续工位 | 在 3–5 个紧凑工位间传递物件 |
| 反馈 / 迭代 | 小循环机制 | 记录、回收、调整一个装置 |
| 决策条件 | 分叉路线 | 在路口举牌、开门或选择轨道 |
| 分类 / 分层 | 架子或抽屉 | 把对象放入对应层级 |
| 抽象系统 | 主隐喻 | 操作一个筛网、闸门、漏斗、管道或秤 |
| 风险 / 卡点 | 聚焦注释 | 守住、修补或被一个瓶颈卡住 |
| 总结 | 带走判断 | 把关键物件装进小盒子或点亮一盏灯 |

避免：满屏卡片、正式流程图、每个节点配一只小黄、把所有内容塞成一张长图、靠换色或换标题位置伪造变化。
